# Futuristic Portfolio

## Files
- `index.html` — Portfolio structure
- `style.css` — Complete styling, animations and responsive design
- `script.js` — Typing effect, mobile menu, scroll animations and project filters

## Easy customization
Search and replace these:
- `IRFAN` — Your name/logo
- `hello@example.com` — Your email
- Hero text and description — `index.html`
- Colors — CSS variables at the top of `style.css`
- Typing words — `words` array in `script.js`
- Projects — Project cards inside the Projects section

## Run
Simply open `index.html` in any modern browser.
